# Anuja Jangale — Creative Developer Portfolio

A responsive, single-page portfolio built with **HTML, CSS, vanilla JavaScript, GSAP, and ScrollTrigger**. No React or other frontend framework is used.



## What's included

- `index.html` — content and semantic page structure
- `style.css` — layout, responsive rules, colors, typography, reduced-motion styles
- `script.js` — preloader, hero timeline, reveal triggers, marquee, floating tech items, pinned horizontal projects, parallax, and the interactive motion lab
- `images/` — original SVG  for the five listed projects
- `logos/` — small SVG technology marks for future use
- `designs/` — three clearly labelled gallery placeholders you can replace with your own work
